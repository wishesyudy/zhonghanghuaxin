# 北京中航华信机电设备安装有限公司 官网设计规格

- 日期：2026-09-19
- 状态：已获用户确认（"暂时按这个来做"）
- 参考风格：tesla.com（大留白、全屏板块、大字号、滚动沉浸）
- 定位：高端大气、简约科技风；深蓝 + 浅灰为主色，金色点缀

## 1. 目标与成功标准

- 单页滚动官网，向业主/物业/机场地铁等 B 端客户展示公司实力：机电工程 + 消防维保 + 智慧消防三驾马车
- 桌面（16:9）与手机 H5（9:16 竖屏 + 16:9 横屏）体验一致
- 动效丰富但不花哨：入场动画、视差、数字滚动、卡片 hover、平滑锚点
- 零依赖纯静态站点：双击 index.html 可预览，上传任意静态托管即上线
- 文案全部来自公司 PPT（中航华信公司介绍（new）.pptx）

## 2. 技术方案

- 纯 HTML + CSS + JS，无框架、无构建、无外部 CDN 依赖（字体用系统字体栈）
- 动效：IntersectionObserver 驱动入场动画（CSS class 切换）；requestAnimationFrame 数字滚动；原生 smooth scroll
- 响应式：CSS Grid / Flex + 媒体查询；断点 1024px / 768px / 480px，同时处理手机横屏
- 单文件结构：`index.html` + `css/style.css` + `js/main.js` + `assets/img/*`

## 3. 视觉系统

### 设计令牌

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--navy` | #0B2A4A | 主色，Hero/页脚背景、深色板块 |
| `--navy-deep` | #061E36 | 更深背景（hover、遮罩） |
| `--blue-bright` | #1E5AA8 | 次级蓝，链接、图标、渐变 |
| `--gray-bg` | #F4F6F9 | 浅灰大留白背景 |
| `--gold` | #C9A54C | 金色点缀：细线、数字、按钮描边、扫光 |
| `--text-dark` | #16212B | 浅底正文 |
| `--text-light` | #E8EEF5 | 深底正文 |
| 字体 | 系统栈 | 中文 PingFang/Microsoft YaHei；英文/数字 Helvetica/Arial + 大标题可加 letter-spacing |

金色使用原则：**只做点缀**，单屏内不超过 3 处（细线、一组数字、一个按钮描边），面积占比 <5%。

### 组件语言

- 卡片：白底、细边框（#E3E8EF）、8px 圆角、hover 微升 4px + 金色顶线渐显
- 按钮：主按钮深蓝底白字（hover 金色扫光动画）；次按钮透明底金边白字
- 章节标题组：金色短线 + 英文小字（如「ABOUT US」）+ 大字中文标题 + 副标题
- Logo：自绘 SVG 几何徽标（六边形/菱形线条寓意「华」）+ 中文「中航华信」+ 英文 ZHONGHANG HUAXIN

## 5. 动效规格

| 动效 | 触发 | 实现 |
|------|------|------|
| 标题逐行上浮 | 加载 | CSS keyframes，stagger delay |
| Ken Burns 背景缩放 | 常驻 Hero | CSS animation，8s 缓动循环 |
| 光点粒子 | 常驻 Hero | canvas，低速上浮，低配设备禁用（prefers-reduced-motion） |
| 板块入场 | 滚动进入视口 | IntersectionObserver 加 .in-view，opacity/translateY 过渡 |
| 数字滚动 | 数据带进入视口 | rAF 缓动计数 |
| 卡片 hover | 指针悬停 | transform 微升 + 金色顶线 + 阴影 |
| 按钮扫光 | hover | ::after 金色渐变条滑过 |
| 平滑锚点 | 点击导航 | scroll-behavior + JS 偏移补偿 |
| 导航高亮 | 滚动 | IntersectionObserver 监听板块切换 active |
| tab/面板切换 | 点击与触摸滑动 | 类切换 + touch 事件横向滑动 |
| 十项闭环点亮 | 进入视口 | 节点逐个 gold 点亮 stagger |
| 证书灯箱 | 点击 | fixed 遮罩 + 大图 + 左右切换 + ESC/点击关闭 |
| 客户 logo 滚动 | 常驻 | 无限横向 marquee（hover 暂停） |

## 6. 响应式规格

- **桌面 ≥1024px**：全宽板块、3-4 列卡片、全屏 Hero
- **平板 768-1024**：2 列卡片、导航保持横排（缩字号）
- **手机 H5 <768**：单列卡片流、汉堡菜单、触摸滑动面板、触控目标 ≥44px；板块 padding 减小
- **手机横屏 (orientation: landscape & max-height: 500px)**：Hero 高度降为 70vh 防溢出，导航压缩
- 图片：`object-fit: cover` + 响应式 `srcset`（证书原图即用，控制 `loading="lazy"` 与尺寸）
